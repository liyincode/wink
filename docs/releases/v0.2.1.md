# Wink v0.2.1

- Start quietly in the menu bar at login without opening the main panel.
- Keep showing the panel when opened manually. Explicit `--settings` launches still open settings.

## Installation

Apple Silicon (M-series), macOS 13 or later. Quit Wink, unzip `Wink-0.2.1-macos-arm64.zip`, and replace Wink in Applications.

Homebrew users can quit Wink, then run `brew update` and `brew upgrade --cask liyincode/tap/wink`.

The app is not notarized. If macOS blocks the first launch, verify the download source, then choose **System Settings → Privacy & Security → Open Anyway**. See [installation help](https://github.com/liyincode/wink/blob/main/docs/development.md#installation).

## Verification and limitations

- Login startup detection was checked with constructed macOS launch events; a full logout/reboot login test remains pending.
- Blackout is not a screen lock. Content may remain faintly visible, and display connection changes may briefly expose it.
- Physical lid/sleep/wake combinations and long idle sessions still need broader testing.
