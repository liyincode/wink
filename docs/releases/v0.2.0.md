# Wink v0.2.0

- Keep your Mac awake while Wink is running with the lid open, whether screens are visible or blacked out.
- Release Wink's keep-awake request when the lid closes, the system sleeps, or Wink quits. Resume after opening or waking with the lid open; closed-lid external-display behavior follows macOS settings.
- Retry displays whose Gamma is temporarily unreadable after connection changes, without restoring healthy displays. Preserve recovery records and retry when a display becomes available.

## Installation

Apple Silicon (M-series), macOS 13 or later. Quit Wink, unzip `Wink-0.2.0-macos-arm64.zip`, and replace Wink in Applications.

The app is not notarized. If macOS blocks the first launch, verify the download source, then choose **System Settings → Privacy & Security → Open Anyway**. See [installation help](../development.md#installation).

## Known limitations

- Blackout is not a screen lock. Content may remain faintly visible, and display connection changes may briefly expose it.
- Physical lid/sleep/wake combinations and long idle sessions still need broader testing.
- Other keep-awake apps can still prevent sleep independently.
