# Wink v0.2.2

- Distribute Wink with Developer ID signing and Apple notarization, including a stapled ticket for Gatekeeper verification.
- Enable Hardened Runtime and secure timestamping for the signed release.
- Retain silent startup at login and the existing screen controls, settings, and recovery records.

## Installation

Apple Silicon (M-series), macOS 13 or later. Quit Wink, unzip `Wink-0.2.2-macos-arm64.zip`, and replace Wink in Applications.

Homebrew users can quit Wink, then run:

```sh
brew update
brew upgrade --cask liyincode/tap/wink
```

## Known limitations

- Blackout is not a screen lock. Content may remain faintly visible, and display connection changes may briefly expose it.
- Full logout/reboot login behavior, physical lid/sleep/wake combinations, and long idle sessions still need broader testing.
