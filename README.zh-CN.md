# Wink

**一键黑屏。**

Wink 起初是为了解决我自己的一个需求：Agent 还在操作电脑，我想离开一会儿，不想让旁人看到屏幕内容，又不想锁屏打断它。于是做了这个 macOS 菜单栏小工具，点击调黑屏幕，回来再点一次恢复显示。

## 安装

**macOS 13 及以上 · Apple Silicon（M 系列芯片）**

[安装说明](docs/development.md#installation)

## 使用须知

- 黑屏不是锁屏，部分显示器仍可能隐约显示内容。
- 拔插显示器时可能短暂亮屏，暴露屏幕内容。
